# Sentinel

Hackathon-winning SwiftUI prototype for predictive home maintenance using weather-risk signals.

## Role

Designed and built by Minwook Shin during the Google x SCAD FLUX Hackathon 2025.

## Stack

Swift, SwiftUI, Figma, Firebase configuration, weather-risk APIs, Gemini API

## What I Built

- Designed the core homeowner risk dashboard and action-plan flow.
- Built the native iOS interface in SwiftUI under a 48-hour hackathon timeline.
- Connected the product concept to live and configurable risk signals such as weather, alerts, and property context.
- Structured the app around practical user decisions: current risk, historical timeline, recommended actions, and insurance-readiness cues.

## Demo

Case study: https://www.minwookshin.com/work/sentinel

## Notes

Built as a hackathon MVP and product prototype. API keys are loaded from environment variables, and the included Firebase plist uses placeholder demo values.
