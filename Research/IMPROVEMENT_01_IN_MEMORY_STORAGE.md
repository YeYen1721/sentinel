## Problem

Tasks generated by Gemini AI disappeared immediately in demo mode:

```
🔄 GENERATING ACTION PLAN WITH GEMINI
✅ Parsed: HVS=58, Tasks=6
✅ GEMINI ANALYSIS COMPLETE
ℹ️  Saving 6 Gemini-generated tasks...
⚠️  Demo mode: Cannot save tasks without Firebase
ℹ️  Demo mode: Returning empty task list  ← Tasks lost!
```

**Impact:**
- Gemini generates perfect 6-task action plans
- User clicks "Generate Action Plan" button
- Loading spinner works correctly
- **But Task List tab shows 0 tasks** ❌

---

## Solution

Added in-memory storage using static properties in `TaskRepository`:

```swift
class TaskRepository: ObservableObject {
    // MARK: - In-Memory Storage for Demo Mode
    private static var demoModeTasks: [MitigationTask] = []
    private static var demoModeProfile: PropertyProfile? = nil

    // ... rest of class
}
```

---

## Edge Cases Handled

**1. Task Sorting**
- Always sorted by `createdAt` descending (newest first)
- Consistent with Firestore ordering

**2. ID Generation**
- Demo mode: `UUID().uuidString`
- Firestore mode: Auto-generated by Firestore

**3. UI Updates**
- All in-memory changes dispatch to `@Published var tasks`
- SwiftUI automatically updates UI

**4. Memory Lifecycle**
- Static storage persists across repository instances
- Cleared when app terminates (expected behavior)

## Known Limitations

**Demo Mode Only:**
- Data lost when app closes (by design)
- No cloud backup
- No multi-device sync

**These are acceptable for demo mode.**

When user enables Firebase, all limitations disappear.
